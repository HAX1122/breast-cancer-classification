# breast-cancer-classification
مشروع يعتمد على خوارزميات تعلم الآلة لتصنيف بيانات سرطان الثدي بناءً على مجموعة بيانات (Breast Cancer Wisconsin). تم تطبيق خوارزميات مثل الانحدار اللوجستي (Logistic Regression) وأشجار القرار (Decision Trees)، بالإضافة إلى استخدام تقنية تحليل المكونات الرئيسية (PCA) لتقليل الأبعاد واستخراج أهم الخصائص المؤثرة في دقة التصنيف.
